Simulation Help Pop-up

    
Simulation items can carry their own overrides without changing your normal brush controls.

    
Override precedence

    
    
      
  • Selected simulation item overrides win whenever that override is set.
    • 
      
  • If an item has no override, the usual brush sidebar setting is used.
    • 
      
  • Changing brush controls never rewrites existing simulation-item overrides.
    • 
    

    
Boid guides

    
    
      
  • Each enabled Boid path animates a moving attraction point along the drawn stroke.
    • 
      
  • Boids steer by vector-summing enabled moving path guides and point attractions.
    • 
      
  • Enabled attract points and moving path targets also provide a soft flock-follow target, so the swarm can notice guides before every boid enters the local guide radius.
    • 
      
  • Per-path strength and radius let you bias one guide more than another.
    • 
    

    
Repulsion hardness

    
    
      
  • Repel points now include hardness, which changes how sharply repulsion ramps up near the source.
    • 
      
  • Lower hardness feels softer and wider; higher hardness feels tighter and stronger near the center.
    • 
    

    
Inspector workflow

    
    
      
  • Use the floating Simulation HUD to place spawn, attract, repel, path, edge, or pheromone items.
    • 
      
  • Use the Settings button in the Simulation HUD to collapse or reopen the right-side simulation inspector.
    • 
      
  • Select an item on the canvas or from the inspector list to edit it in the right-side overlay.
    • 
      
  • Disable an item to keep it in the scene without deleting it.
    • 
    

    
Brush behavior

    
    
      
  • Outside Simulation mode, boid and ant brushes keep using the normal sidebar settings.
    • 
      
  • Simulation mode layers per-item overrides on top of those brush defaults.
    •

Graph Editor Help

          
Sketch: choose a tool, then click the canvas to place points. Double-click finishes polyline and bezier creation. Double-click a bezier anchor to toggle smooth or sharp.

          
Radial: place a center first, then a spoke handle. The editor creates grouped independent lines, and you can adjust spoke count and spread from the Selection panel after placement.

          
Navigate: Pan tool drags the view with the mouse, mouse wheel scrolls, Ctrl+wheel zooms, and touch uses two-finger pan and pinch.

          
Authoring cues: size handles rise above a node, speed handles extend to the right, and start-mode badges on the path show whether agents begin evenly or randomly.
